Política de Privacidade

Esta aplicação destina-se exclusivamente a uso pessoal.

Acede, mediante autorização, ao conteúdo e aos metadados dos ficheiros para criar cópias de segurança. Não altera nem elimina os ficheiros de origem.

As cópias são armazenadas no destino configurado pelo utilizador, podendo ser processadas pelos fornecedores dos serviços envolvidos. São conservadas até serem eliminadas pelo utilizador.

As credenciais são guardadas no dispositivo onde a ferramenta é executada. Os registos podem conter nomes de ficheiros e informações técnicas.

Os dados não são publicados neste site, vendidos, usados para publicidade ou para treinar modelos de inteligência artificial.

O utilizador pode revogar o acesso nas definições da conta Google. Essa revogação não elimina as cópias já realizadas.

A utilização dos dados Google respeita a Google API Services User Data Policy, incluindo os requisitos de Limited Use.
